# UI دوزبانه: فارسی و English

## این چیست؟
UI موبایل زول (چت، فید، ایده‌ها، هدف‌ها، کتابخانه، تأییدها، حافظه، تنظیمات، اتصال‌ها، راه‌اندازی اول) دو زبان دارد: **فارسی** (پیش‌فرض و راست‌به‌چپ) و **English**. زبان را از **تنظیمات ← زبان اپ** عوض می‌کنی.

این UI مال خود OpenMuse 0.6.0 است (لایسنس MIT). سورسش را به `engine/web/` آوردیم و فارسی‌اش کردیم، چون UI داخل پکیج pip از قبل build شده است و نمی‌شود ترجمه‌اش کرد. ریپوی OpenMuse بایگانی شده و ادامه‌اش nanoMuse است که لایسنس GPL دارد، پس روی 0.6.0 می‌مانیم.

## چه کار می‌کند؟
- **پیش‌فرض فارسی است**، هر زبانی که مرورگر داشته باشد. انتخاب روی هر دستگاه جدا نگه داشته می‌شود (`localStorage` با کلید `zoul_locale`). تغییر زبان فوری است و reload نمی‌خواهد.
- **راست‌به‌چپ:**
  - با فارسی، `<html dir="rtl" lang="fa">` می‌شود و چیدمان آینه می‌شود.
  - فاصله‌ها و جای‌گذاری‌ها با کلاس‌های منطقی Tailwind نوشته شده‌اند (`ms/me/ps/pe/start/end/text-start/rounded-es/...`).
  - فلش‌ها و شورون‌ها کلاس `rtl-flip` دارند و در فارسی آینه می‌شوند.
- **جهت خودکار متن:** پیامی که کاربر یا مدل نوشته جهتش را از خودش می‌گیرد (`unicode-bidi: plaintext`). جواب انگلیسی در اپ فارسی چپ‌چین می‌شود و برعکس.
- **کد، آدرس، ایمیل و مسیر** همیشه چپ‌به‌راست‌اند.
- **عدد و تاریخ:**
  - عددهای داخل متن‌ها (مثل «۳ دقیقه پیش») با ارقام فارسی نوشته می‌شوند.
  - تاریخ‌ها با `Intl` و `fa-IR` نوشته می‌شوند، یعنی شمسی با ارقام فارسی.
- **فونت:** متن فارسی با وزیرمتن (OFL) از پکیج `@fontsource-variable/vazirmatn` و متن لاتین با Figtree. هر دو از خود سرور می‌آیند، نه CDN.
- **برند:** همه‌جا «زول» / «Zoul» است. اسم پیش‌فرض ایجنت `زول` است (`engine/openmuse/config.toml`).
- **زبان جواب ایجنت** جداست: تنظیمات ← زبان جواب. پیش‌فرض «مثل زبان من» است و گزینهٔ «فارسی» هم اضافه شده.

## کجای کد است؟
| فایل | نقش |
|---|---|
| `engine/web/src/i18n/index.ts` | زبان‌ها (`fa`، `en`)، پیش‌فرض، `t()`، `dir`، ارقام فارسی، `intlLocale()` |
| `engine/web/src/i18n/fa.ts` | **همهٔ متن‌های فارسی** (حدود ۷۲۰ عبارت). کلید هر عبارت متن انگلیسی است |
| `engine/web/src/i18n/en.ts` | فقط عوض کردن برند OpenMuse به Zoul در انگلیسی |
| `engine/web/src/i18n/i18n.test.ts` | تست‌ها: هر `t("...")` در کد ترجمهٔ فارسی دارد، جاگذارها یکی‌اند، ترجمهٔ خالی نداریم |
| `engine/web/src/index.css` | فونت‌ها و قاعده‌های راست‌به‌چپ |
| `engine/web/index.html`، `public/manifest.webmanifest` | عنوان «زول»، `lang="fa" dir="rtl"` |
| `engine/web/LICENSE.openmuse` | لایسنس MIT سورس اصلی |
| `Dockerfile` (مرحلهٔ `ui`) | `npm ci`، بعد `npm test`، بعد `npm run build`، و گذاشتن خروجی جای UI انگلیسی داخل پکیج |

## اضافه کردن یا تغییر یک متن
1. در کد UI متن را انگلیسی و داخل `t("...")` بنویس.
2. همان کلید را با ترجمهٔ فارسی در `fa.ts` اضافه کن. جاگذارهای `{name}` باید دقیقاً همان باشند.
3. `npm test` را اجرا کن. اگر ترجمه‌ای جا افتاده باشد، تست اسمش را می‌گوید و **بیلد Docker هم می‌شکند**.
4. برای فاصله و جای‌گذاری از کلاس‌های منطقی استفاده کن (`ms-2` به‌جای `ml-2`، `text-start` به‌جای `text-left`). آیکون جهت‌دار هم کلاس `rtl-flip` بگیرد.

## تست
- خودکار: `cd engine/web && npm test && npm run typecheck && npm run lint` (۲۶ تست).
- دستی، که روی همین پشته (nginx، جنگو و موتور) با Chrome در اندازهٔ گوشی انجام شد:
  - صفحه‌های ورود با توکن، راه‌اندازی اول، چت، فید، هدف‌ها، منوی آواتار و تنظیمات در هر دو زبان.
  - عوض کردن زبان از تنظیمات (فوری، و بعد از reload هم می‌ماند).
  - پیام فارسی-انگلیسی در حباب چت.

## نکته‌ها و محدودیت‌ها
- **چند متن از سرور پایتون می‌آید و انگلیسی می‌ماند:** پیام خطاها، دلیل‌های Sentinel، اسم ابزارها و حالت‌ها (مثل `ask`). برچسب‌های کار پس‌زمینه («Reminder: ...») را UI خودش ترجمه می‌کند (`localLabel`).
- اسم پروفایل ایجنت همانی است که ذخیره شده. اگر قبلاً «Zoul» ذخیره شده باشد، از تنظیمات ← اسم عوضش کن.
- اپ اندروید OpenMuse (`android/`) آورده نشده است.
