# صفحهٔ اصلی و بررسی سلامت (اپ `home`)

## این چیست؟
اولین صفحهٔ زول و آدرس بررسی سلامت که همروش برای فهمیدن «سرویس زنده است؟» صدا می‌زند.

## چه کار می‌کند؟
- **`/zoul/`**: اسم و نسخهٔ زول (از `version.txt`) را نشان می‌دهد و می‌گوید موتور ایجنت روشن است یا نه. اگر موتور پایین باشد صفحه باز هم باز می‌شود و فقط پیام «موتور در دسترس نیست» را نشان می‌دهد.
- **`/health/`**: جواب JSON `{"status": "ok", "version": ...}`. عمداً به موتور سر نمی‌زند، تا مشکل موتور باعث ری‌استارت کل کانتینر نشود.
- فعلاً ورود ندارد (تک‌کاربره). پنل ادمین جنگو در `/admin/` است.

## کجای کد است؟
| فایل | نقش |
|---|---|
| `home/views.py` | `index` و `health` |
| `home/urls.py` | مسیرهای `/zoul/` و `/health/` (ریشهٔ `/` مال UI موتور است: [gateway.md](gateway.md)) |
| `home/templates/home/index.html` | صفحهٔ تیرهٔ راست‌به‌چپ |

## تنظیمات
ندارد. نسخه از `version.txt` در ریشهٔ مخزن خوانده می‌شود.

## تست
`home/tests.py`: بررسی می‌کند `/health/` به موتور درخواست نمی‌فرستد، `/zoul/` با موتور خاموش هم باز می‌شود، و جنگو روی `/` چیزی ندارد.

## نکته‌ها
- در همروش Readiness Probe را `/health/` بگذارید. nginx آن را با Host `localhost` به جنگو می‌دهد، پس IP داخلی پاد مشکلی ندارد.
