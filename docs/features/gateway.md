# دروازه: nginx روی پورت 8000

## این چیست؟
همروش فقط یک پورت (`8000`) را بیرون می‌دهد، ولی داخل کانتینر دو سرویس وب داریم: جنگو و موتور OpenMuse. nginx روی `8000` می‌نشیند و هر درخواست را به سرویس درستش می‌فرستد. با این کار UI موبایل خود OpenMuse (چت، تأییدها، هدف‌ها، حافظه) روی همان دامنهٔ زول باز می‌شود.

## چه کار می‌کند؟
| آدرس روی `zoul.darkube.ir` | می‌رود به |
|---|---|
| `/` ، `/api/...` ، `/ws` ، `/assets/...` و بقیه | موتور OpenMuse (`127.0.0.1:8787`) |
| `/admin/` | پنل ادمین جنگو (`127.0.0.1:8001`) |
| `/zoul/` | صفحهٔ وضعیت زول ([home.md](home.md)) |
| `/health/` | بررسی سلامت جنگو |
| `/engine/` | وضعیت موتور از دید جنگو ([engine.md](engine.md)) |
| `/static/` | فایل‌های استاتیک جنگو |

- **ورود به UI:** یک بار `https://zoul.darkube.ir/?token=<OPENMUSE_SERVER_TOKEN>` را باز کن. اپ توکن را نگه می‌دارد و می‌شود آن را به صفحهٔ اصلی گوشی اضافه کرد. بدون توکن، API جواب `401` می‌دهد و WebSocket بسته می‌شود.
- **WebSocket:** چت زنده روی `/ws` است و nginx هدرهای `Upgrade` را رد می‌کند. تا یک ساعت بی‌کاری قطع نمی‌شود.
- **بدون بافر:** پاسخ‌های موتور همان لحظه به گوشی می‌رسند.
- **آپلود:** فایل تا ۳۰ مگابایت پذیرفته می‌شود (حد موتور ۲۵ مگابایت است).
- **لاگ بدون توکن:** در لاگ دسترسی فقط مسیر (`$uri`) ثبت می‌شود، نه query string، تا `?token=...` در لاگ همروش نماند.
- **probe همروش:** درخواست سلامت همروش با IP داخلی پاد می‌آید و جنگو در حالت `DEBUG=False` چنین Hostی را رد می‌کند. nginx برای `/health/` Host را `localhost` می‌گذارد، پس Readiness Probe را می‌شود روی `/health/` گذاشت.

## کجای کد است؟
| فایل | نقش |
|---|---|
| `deploy/nginx.conf` | قاعده‌های مسیریابی |
| `docker-entrypoint.sh` | اجرای موتور و gunicorn در پس‌زمینه (هر کدام در حلقهٔ ری‌استارت) و nginx به‌عنوان پروسهٔ اصلی |
| `Dockerfile` | نصب nginx و `nginx -t` در زمان بیلد، تا کانفیگ خراب هیچ‌وقت به سرور نرسد |
| `config/settings.py` | `SECURE_PROXY_SSL_HEADER`: جنگو https بودن را از هدر nginx می‌فهمد (برای CSRF فرم ادمین) |

## تنظیمات
ندارد. پورت‌ها ثابت‌اند: `8000` بیرونی، `8001` جنگو و `8787` موتور.

## تست
- `home/tests.py`: صفحهٔ جنگو زیر `/zoul/` است و `/` در جنگو خالی است.
- این‌ها روی همین پشته (nginx، gunicorn و موتور) دستی تست شده‌اند:
  - همهٔ مسیرهای جدول بالا.
  - WebSocket: با توکن درست کد `101` گرفت و پیام `hello` آمد. با توکن غلط رد شد.
  - ورود به ادمین با CSRF پشت https.
  - `/health/` با Host به شکل IP داخلی.
  - نبودن توکن در لاگ.
- لوکال: `docker compose up --build`، بعد باز کردن `http://localhost:8000/?token=...`.

## نکته‌ها و محدودیت‌ها
- اگر nginx بمیرد کانتینر هم می‌میرد و همروش آن را دوباره بالا می‌آورد. این عمدی است.
- UI از `engine/web/` ساخته می‌شود و دوزبانه است ([i18n.md](i18n.md)).
